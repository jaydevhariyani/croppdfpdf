# CropPDFPDF — Free Online PDF Crop Tool

Clean, privacy-first PDF cropper that runs entirely in the browser.

**Live demo style:** similar to pdfresizer.com/crop  
**Processing:** 100% client-side (PDF.js + pdf-lib) — files never leave the user’s device.

## Features

- Visual crop with free-hand resize (drag corners)
- Auto-crop white margins
- Extend margins
- Perfect for e-commerce shipping labels (Flipkart, Meesho, Myntra, AJIO, Amazon, LimeRoad, Nykaa)
- No registration, no watermarks
- Mobile-friendly

## Deploy on GitHub Pages

1. Create a new repository (e.g. `croppdfpdf` or `username.github.io`)
2. Upload `index.html` (and this README)
3. Enable GitHub Pages → Source: main branch / root
4. Site will be live at `https://username.github.io/croppdfpdf/` (or your custom domain)

## Privacy

All PDF processing happens inside the browser. No files are uploaded to any server.
