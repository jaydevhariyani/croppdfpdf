# CropPDFPDF

**Free Online PDF Crop Tool for Shipping Labels**

Crop Flipkart, Meesho, Myntra, Ajio, Amazon, Limeroad, Nykaa & eBay shipping labels in seconds.

---

## Features

- **First page only preview** — Fast even for 100–500 page PDFs
- **One crop → All pages** — Draw once on page 1, applied to every page
- **Resizable selection box** — Drag, move, resize freely
- **Optional text watermark** — Position, opacity & size controls
- **100% Private** — All processing happens in your browser (no server upload)
- **No signup required**

## Supported Platforms

Flipkart • Meesho • Amazon • Myntra • Ajio • Limeroad • Nykaa • eBay

## How to Use

1. Open `index.html` in browser (or host the folder)
2. Upload your multi-page shipping label PDF
3. Draw crop box on the first page
4. (Optional) Enable watermark
5. Click **Crop & Download**
