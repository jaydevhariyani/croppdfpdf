Online PDF crop tool

Free and easy to use online tool for visual PDF document cropping / changing canvas size. With this tool, you can easily crop scans, Flipkart labels, Amazon labels, logos, and any other PDFs.

You can crop the PDF to a selected area, to try and remove all margins automatically. You can also use PDF cropper to increase visible margins, for example, to add extra space for annotations.

How to Crop a PDF

  1. Upload your document. If you wish to upload multiple files simultaneously, please ensure that they are of the same size and margins.
  2. If you want to select the part of the document for cropping manually, mark it in the preview window and then choose the Crop to selection option.
  3. It is important to note that all pages in the processed documents will be cropped equally. If you require different parts of each page to be cropped, we recommend splitting the file before manually cropping each page.

Cropping Options

  • Crop to selection: Visually select the area you want to keep using the interactive cropping tool.
  • Label Cropping: Use this PDF cropper to cut shipping labels, Flipkart labels, Meesho labels, and other e-commerce labels to the correct size. Upload your label PDF, use the visual crop tool to select just the label area, and download a perfectly sized label ready for printing.

All files are processed securely in your browser and automatically deleted within 1 hour of upload.

Frequently Asked Questions

How do I crop a PDF online?
Upload your PDF, then either drag to select the area you want to keep. Click the crop button to process.

Does cropping apply to all pages in the PDF?
Yes. The same crop settings are applied to all pages. If you need different crops for different pages, split the PDF first, crop individual pages, then merge them back together.
